분산 수집 및 인프라 현대화

레거시 현대화 및 웹 마이그레이션

기존 C# 데스크톱 프로그램 및 JSP 스파게티 레거시 시스템을 Spring Boot 및 표준 웹 아키텍처로 현대화합니다. 소스코드와 명세가 소실된 모듈을 역공학하여 정합성을 유지하며 신속히 웹으로 마이그레이션합니다.

정밀 정산 및 비즈니스 트랜잭션 설계

의료 수가 정산, 회계 연/반기 정산 등 정밀함이 요구되는 금융 및 물류 회계 트랜잭션을 설계합니다. 부동 소수점 오차를 완전히 배제하는 아키텍처를 도입하여 1원의 정산 오차도 없는 신뢰성 높은 시스템을 보장합니다.

보안성 확보 및 실무 유틸리티 최적화

Fail2ban을 운영 인프라에 적용하여 포트 스캔 및 Brute-Force 등 악의적인 접근을 로그 패턴 기반으로 탐지 및 차단하여 서버 안정성을 보장합니다. JWT/bcrypt 기반 사용자 인증 보안과 xlsx 모듈을 활용한 대용량 엑셀 처리 유틸리티를 구축하여 보안 및 실무 편의성을 극대화합니다.

Fail2ban & Security Access Control Policy
배경

앤드와이즈 대학 통합 CMS 솔루션 운영 및 기술지원 중, 특정 대학 포털의 파일 다운로드 엔드포인트에 자동화 스크립트를 통한 무차별 무작위(Brute Force) 호출 및 크롤링 공격이 유입되어 WAS CPU 사용률이 99%까지 치솟고 서버 리소스가 마비되는 인시던트 발생.

성장

서버 액세스 로그(Access Log)를 실시간 모니터링하여 단시간에 과도한 임계치 요청을 보내는 공격 IP를 식별하고, Fail2ban 데몬과 리눅스 방화벽(IPtables) 정책을 연동하여 탐지 즉시 해당 IP를 동적으로 영구 차단하는 자동화 관제 정책을 셋업 완료.

Composite Index & SQL Execution Plan Tuning
배경

다인이엔씨 지반 계측 플랫폼 운영 중, 특정 현장의 센서별 천만 건 이상의 대용량 계측 로그 데이터를 기간 조건 및 센서 ID로 조인(JOIN)하여 조회할 때, 테이블 풀 스캔(Full Scan) 및 임시 디스크 테이블 정렬 유발로 인해 조회 쿼리가 타임아웃(Timeout)되는 데이터베이스 병목 장애 발생.

로컬 계측 로그 수집 및 파일 로테이션 제어

Java Swing File Watcher & Backup Rename Rotation
배경

다인이엔씨 지반 계측 현장의 계측 장비 PC 내 파일 감지(Swing File Watcher)를 통한 DB 업로드 유틸리티 운영 시, 계측 물리 센서가 원천 파일에 데이터를 실시간 기록(Append) 중일 때 유틸리티가 동시에 읽기 접근을 시도하여 파일 Lock 충돌 및 데이터 유실, 중복 DB 전송 오류 수시 발생.

성장

감지 경로 내 파일 생성 상태와 전송 완료 플래그를 정밀 통제하기 위해, 업로드가 성공한 파일은 날짜 스탬프와 성공 접미사(예: _SUCCESS)를 붙여 별도 백업 디렉토리로 안전하게 이름 변경 및 이관(Rename Rotation)하는 고유 파일 라이프사이클을 설계하여 데이터 신뢰도 100% 달성.

#로컬파일제어 #데스크톱UI #파일로테이션

정적 빈 컬렉션을 활용한 객체 생성 억제

Collections.emptyList() & emptyMap()
배경

세인티 소상공인 ERP 백엔드 REST API 설계 및 매출/매입 통계 엔진 구축 중, 조회 데이터가 존재하지 않는 빈 날짜나 항목에 대해 API 응답 시마다 매번 new ArrayList() 또는 new HashMap() 객체를 반복 생성하여 JVM 힙 영역의 단명(Short-lived) 객체가 기하급수적으로 축적되는 비효율 발견.

성장

가비지 컬렉터(GC)가 매 요청마다 생성되는 무의미한 빈 인스턴스를 수거해야 하는 부하를 절감하고자, 정적으로 미리 생성되어 메모리에 상주하는 Collections.emptyList() 및 emptyMap() 싱글톤 반환 구조로 리팩토링하여 GC 오버헤드를 억제.

#방어적코딩 #싱글톤_메모리절약 #JVM_힙최적화

대용량 문자열 연산 최적화

String vs StringBuilder Memory Allocation
배경

다인이엔씨 공공기관 폐쇄망 내부에서 로컬 계측 텍스트 데이터를 DB에 업로드하는 Java Swing 유틸리티 개발 중, 수십만 라인의 CSV 로그 파일을 파싱하여 문자열로 조합하는 루프문 내에서 String '+' 연산 누적으로 인한 로컬 PC 메모리 포화 및 화면 멈춤(Freezing) 현상 발생.

성장

Java String의 불변성(Immutability) 특징으로 인해 매 루프마다 새로운 String 객체가 JVM 힙 메모리에 생성되어 GC 병목을 유발함을 파악. 가변 버퍼인 StringBuilder를 적용하여 데이터 변환 및 문자열 파싱 처리 속도를 10배 이상 고속화하고 가비지 생성을 차단.

#힙메모리_최적화 #StringBuilder #GC부하방지
