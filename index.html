데이터 아키텍처 및 쿼리 최적화

비정규화된 대용량 센서/생산 데이터베이스를 정규화된 관계형 모델로 재설계하여 **데이터 정합성을 100% 확보**합니다. 복합 인덱스(Composite Index) 및 실행 계획 분석을 통해 대용량 수치 조회 쿼리 성능을 비약적으로 개선합니다.

분산 수집 및 인프라 현대화

PLC 및 센서 설비로부터 발생하는 원천 데이터를 **Node-RED 기반 병렬 처리 파이프라인**을 활용해 안정적으로 수집하고 자동 파싱합니다. Nginx 기반 멀티 테넌시를 적용하여 분산된 클라이언트 배포 구조를 단일 패키지로 효율화합니다.

보안성 확보 및 실무 유틸리티 최적화

Fail2ban을 운영 인프라에 적용하여 포트 스캔 및 Brute-Force 등 악의적인 접근을 로그 패턴 기반으로 탐지 및 차단하여 **서버 안정성을 보장**합니다. JWT/bcrypt 기반 사용자 인증 보안과 xlsx 모듈을 활용한 대용량 엑셀 처리 유틸리티를 성공적으로 도입했습니다.

01

자원 관리의 효율화 (Try-with-Resources)

배경

Java Swing 기반 공공기관 데이터 수집 에이전트 개발 중, 다량의 로컬 계측 파일 스트림 및 DB 커넥션 처리 과정에서 예외 발생 시 자원이 닫히지 않아 락(Lock)이 걸리고 OOM이 발생하는 누수 현상이 관찰되었습니다.

성장

단순히 try-catch-finally 블록을 이용해 일일이 자원을 close하는 구조의 누락 취약성을 확인했습니다. JVM 내부 자원 정리 스펙인 AutoCloseable 인터페이스와 try-with-resources를 적용하여 자원 자동 반납을 보장하고 에이전트 구동 안정성을 획기적으로 개선했습니다.

#자원누수방지 #코드안정성 #AutoCloseable
02

대용량 파싱 시 메모리 최적화 (String vs StringBuilder)

배경

수십만 라인의 대용량 원천 텍스트 파일(CSV 로그 데이터)을 파싱하여 특정 데이터셋 규격에 맞춰 문자열을 변환해 적재할 때, 문자열 누적 연산 시 인스턴스가 힙 영역을 포화시켜 빈번한 GC 유발로 연산 성능이 폭락하는 현상이 있었습니다.

성장

Java String의 불변성(Immutability)에 대한 물리적 이해를 바탕으로 루프 내 무분별한 + 결합 연산이 갖는 비효율을 짚어냈습니다. 가변적인 버퍼 처리를 지원하는 StringBuilder를 도입하여 문자열 파싱 가공 성능을 10배 이상 향상시켰습니다.

#가비지컬렉션_개선 #StringBuilder #대용량파싱
03

객체 할당 방지와 방어적 코딩 (Collections.emptyMap/List)

배경

조회 쿼리 결과 데이터가 존재하지 않는 다수의 RESTful API 요청 처리가 일어나는 백엔드 환경에서, 습관적으로 new HashMap() 또는 new ArrayList()를 새로 동적 할당하여 응답 개체를 만드는 객체 오버헤드를 줄이고자 했습니다.

성장

데이터가 비어 있는 상황에서도 굳이 메모리 힙 영역에 인스턴스를 추가 할당할 필요가 없다는 판단하에, JVM 싱글톤 패턴으로 사전에 메모리에 상주하는 Collections.emptyMap() 및 emptyList()를 적용하여 불필요한 객체 생성을 원천 차단하고 메모리 효율을 극대화했습니다.

#방어적코딩 #싱글톤_반환 #메모리점유_최적화
04

AI 코파일럿 기반 자동화 및 서버 장애 대응 (Claude Code & System Config)

배경

대학교 CMS 솔루션 유지보수 시 다수 서버의 개별 설정 및 반복적인 배포 과정에서 발생하는 수작업 실수(Human Error)와, 예기치 못한 운영 인프라 장애 발생 시 신속한 덤프 로그 추적과 진단의 한계를 마주했습니다.

성장

**Claude Code 에이전트 스킬**과 리눅스 CLI 자동화 스크립트를 융합하여 정형화된 서버 모니터링 및 반복 배포 프로세스를 자동화했습니다. 또한 Nginx 및 WAS(Tomcat) 환경 설정을 표준화하고, 장애 발생 시 리눅스 커널 로그 분석을 신속히 수행하는 장애 조치 능력을 길렀습니다.

#Claude_Code_협업 #업무자동화_스크립트 #리눅스_장애대응
