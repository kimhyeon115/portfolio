- **Backend** — Java 17, Spring Boot 3.2(멀티모듈), Spring MVC, MyBatis, Node.js(Express)
- **Frontend** — TypeScript, React, Next.js, JavaScript, jQuery
- **Database** — MySQL, MariaDB, Tibero, Redis
- **Infra** — Linux, Nginx, Apache Tomcat, Jenkins, Git/GitLab
- **AI 개발 도구** — Claude Code, Codex, Grok (역할 분담 활용)
